# Agents

[CONTRIBUTING.md](CONTRIBUTING.md) applies to every change, including its section on releasing.
Maintainers add:

- A branch merges to `main` with `--no-ff` and is then deleted.
- The history is public: commit with the repository-local `user.email`, and a branch, commit or
  file names only this repository's own issues.
- The checks' verdict is their exit code.
