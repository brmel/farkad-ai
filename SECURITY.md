# Security Policy

Only the latest release receives fixes.

## Reporting a vulnerability

Never in a public issue, discussion or pull request. Report it privately:

- [open a private advisory](https://github.com/brmel/farkad-ai/security/advisories/new), or
- email mellah.brahim.redouane@gmail.com.

Include what an attacker could do, the steps or input that reproduce it, and your Python version,
OS and model provider.

You get an acknowledgement within 3 working days and a timeline once severity is assessed. The
fix ships in a patch release, credited to you unless you prefer otherwise. The live service at
[farkad.web.app](https://farkad.web.app) is covered by the same address.
